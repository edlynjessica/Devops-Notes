# 🐚 Shell and Terminal

## Overview

The **Shell** and the **Terminal** are two closely related concepts in Linux, but they are **not the same**.

- The **Terminal** is the application where users type commands.
- The **Shell** is the program that interprets those commands and communicates with the operating system.

Understanding the difference between these two is fundamental to working with Linux.

---

## What is a Shell?

A **Shell** is a **command-line interpreter** that acts as an interface between the **user** and the **operating system**.

It reads commands entered by the user, interprets them, and communicates with the **Linux Kernel** through **System Calls** to perform the requested operation.

> 💡 **Key Point**
>
> The Shell **does not directly communicate with the hardware**. It requests services from the **Kernel** using **System Calls**.

---

## Why Do We Need a Shell?

Without a shell, users would have no way to execute commands from the command line.

The shell is responsible for:

- Reading user commands
- Interpreting commands
- Executing programs
- Making System Calls when required
- Displaying the command output

For example, when you type:

```bash
pwd
```

The shell understands what `pwd` means and executes the appropriate program.

---

## How Does the Shell Work?

When a command is entered, the shell performs the following steps:

1. Reads the command.
2. Checks whether it is valid.
3. Executes the required program.
4. Makes System Calls to the Kernel if necessary.
5. Displays the output to the user.

### Command Execution Flow

```text
You type:
ls

        │
        ▼
Shell reads the command

        │
        ▼
Runs the "ls" program

        │
        ▼
System Call

        │
        ▼
Linux Kernel

        │
        ▼
Reads the directory

        │
        ▼
Returns the result

        │
        ▼
Shell displays the output
```

---

## What is a Terminal?

A **Terminal** is an application that provides a **text-based interface** for interacting with the operating system.

It allows users to:

- Enter commands
- View command output
- Interact with a shell

Unlike the shell, the terminal **does not interpret commands**. It simply accepts user input and displays the output generated by the shell.

---

## Terminal vs Shell

| Terminal | Shell |
| :--- | :--- |
| Application / Program | Command-Line Interpreter |
| Accepts keyboard input | Interprets user commands |
| Displays command output | Executes commands |
| Provides the Command Line Interface (CLI) | Communicates with the Kernel |
| Does not understand commands | Understands and executes commands |

> 💡 **Remember**
>
> **Terminal = Where you type commands.**
>
> **Shell = What understands and executes those commands.**

## What is Bash?

**Bash** stands for **Bourne Again SHell**.

It is the **default shell** for many Linux distributions and is widely used for:

- Executing commands
- Shell scripting
- Automation
- Variables
- Loops
- Functions
- Aliases

Most Linux tutorials and DevOps tools assume the use of **Bash**.

---

## System Calls

A **System Call** is a request made by an application or shell to the **Kernel** to perform an operation that requires hardware access.

Common examples include:

- `read()`
- `write()`
- `open()`
- `close()`
- `fork()`
- `exec()`

Applications and shells cannot directly access hardware. They must use System Calls to communicate with the Kernel.

---

## Real-Life Example

Suppose you execute:

```bash
mkdir notes
```

The following sequence occurs:

```text
User
   │
   ▼
Terminal
   │
   ▼
Shell receives the command
   │
   ▼
System Call
   │
   ▼
Kernel creates the directory
   │
   ▼
Shell receives the result
   │
   ▼
Terminal displays the output
```

> 💡 **Key Point**
>
> The **Shell does not create the directory**.
>
> The **Kernel** performs the operation after receiving a System Call from the Shell.

---

## ✅ Key Takeaways

- The **Terminal** is the application where users type commands.
- The **Shell** is the command-line interpreter that executes commands.
- The Shell communicates with the Kernel using **System Calls**.
- The Kernel performs hardware-related operations.
- Bash is the most widely used Linux shell.
